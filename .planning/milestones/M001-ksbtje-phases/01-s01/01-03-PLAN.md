<objective>
ProfileStore 구현 — safeStorage 암호화 저장/불러오기 + IPC
</objective>

<context>
Phase: 01 (s01) — Milestone: M001-ksbtje

Electron safeStorage API를 사용하여 신청 프로필(birthDate, phoneNumber, membershipNumber 등)을 OS 수준 암호화로 저장하고 불러오는 ProfileStore를 구현한다. 앱 재시작 후에도 프로필이 복호화되어 로드되며, 사용자가 확인 후 사용하는 흐름을 지원한다.
</context>

<must_haves>

- safeStorage.isEncryptionAvailable() 체크 — 비활성화 시 평문 저장 거부
- 프로필 데이터 OS 수준 암호화 저장 (macOS Keychain / Windows DPAPI)
- 앱 재시작 후 프로필 복호화 로드
- clearProfile로 프로필 삭제
- 프로필 데이터 로그 마스킹

</must_haves>
