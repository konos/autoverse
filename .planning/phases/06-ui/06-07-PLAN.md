       절차를 반복해 반대 방향도 확인한다.

    2. **최초 고지 차단 (R021).** 설정 파일의 고지 확인 값을 지운 상태(또는 새 사용자 상태)에서
       API 탭을 처음 누르면 모달이 뜨고, **취소/Esc 로 닫으면 브라우저 탭이 그대로 활성**이어야
       한다. 확인 버튼을 눌러야만 API 모드로 바뀐다. 창을 최소 크기로 줄인 상태에서도 확인
       버튼에 도달할 수 있는지 함께 본다. 확인 후 같은 탭을 다시 눌렀을 때 모달이 재노출되지
       않아야 한다.

    3. **환경변수 잠금 (R016/D-06).** `AUTOVERSE_LOGIN_MODE=api npm run dev` 로 실행 →
       두 탭이 모두 비활성이고 `환경변수로 고정됨` 배지와 현재 적용 중인 모드 라벨이 보여야 한다.
       탭을 눌러도 아무 변화가 없어야 하고, 배지 문구에 환경변수 원문 값이 보이면 안 된다.

       설명 문구가 뜨는지 확인한다. 만약 Weverse 보안 확인(캡차)이 실제로 뜨면, 안내가 보안
       확인을 설명하고 브라우저 로그인 전환 버튼을 함께 보여주는지 확인한다 — **캡차를 인위적으로
       유발하려 시도하지 말 것.** 캡차가 뜨지 않으면 그 항목은 "미관측"으로 기록한다(통과로
